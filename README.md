# webUMKM

Platform website UMKM berbasis template.

## Template pertama

`templates/umkm-modern/` adalah template **UMKM Modern** yang dirancang agar satu template dapat digunakan berulang kali dengan data bisnis yang berbeda.

### Struktur

- `index.html` — struktur halaman
- `style.css` — tampilan responsif
- `data.js` — data bisnis, produk, galeri, dan testimoni
- `app.js` — mengisi template dari data dan membuat tombol WhatsApp dinamis
